# TOT Insights Hub — Templates & Guides

This folder contains everything needed to contribute to the TOT Insights Hub platform.

## Start here
1. Read `STYLE_GUIDE.md` before creating anything
2. Use `WORKFLOW_GUIDE.md` for step-by-step instructions on common tasks

## Templates
| File | Use for |
|------|---------|
| `briefing_template.html` | Short findings-led research outputs |
| `paper_template.html` | Full analytical papers with theory and footnotes |
| `policy_brief_template.html` | Recommendations-focused outputs for policymakers |
| `primary_sources_template.html` | Source document collections, no Key Findings needed |
| `dashboard_template.html` | Interactive data visualisations with Chart.js |

## Rules
- Never publish a page with ALL-CAPS placeholder text still in it
- Always run the site audit after a batch of changes
- Questions: contact the platform lead
